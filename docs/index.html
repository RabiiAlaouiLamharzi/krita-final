Krita UI Learning Study

Download the study build for your computer, open it, and log in with the credentials your experimenter sent you. Same study software on macOS and Windows (Krita 5.3.2).

Download for macOS Download for Windows

How to run

  1. Download the zip for your OS from the latest release.
  2. Unzip. Keep the folder together.
  3. Mac: unzip, then double-click Launch Study.command (not Krita.app). If macOS blocks the command: Right-click → Open. Opening Krita.app alone after download often shows a false “damaged” warning — the launcher clears that.
  4. Windows: double-click Launch Study.bat (if SmartScreen appears: More info → Run anyway).
  5. Enter Participant ID, Condition, Session, and password from your experimenter.

What you get

  • Krita with the study plugin already packaged
  • Full session flow (learning, recall, surveys) — text and images on the right panel
  • No ffmpeg / no tutorial videos in this package

Source code: github.com/RabiiAlaouiLamharzi/krita-final · Builds are attached to Releases . After each new release, prefer the assets named KritaStudy-macOS-*.zip and KritaStudy-Windows-*.zip.
