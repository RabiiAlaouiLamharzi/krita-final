Krita UI Learning Study

Follow these steps on your computer. Use the login details your experimenter sent you.

1. Download Krita 2. Download the study pack

On a Mac

  1. Install Krita from the link above. Drag it into Applications, then open it once.
  2. Download and unzip the study pack.
  3. Right‑click Launch Study.command → Open → Open.
  4. Log in when Krita opens.

On Windows

  1. Install Krita from the link above, then open it once.
  2. Download and unzip the study pack.
  3. Double‑click Launch Study.bat. If Windows warns you, choose More info → Run anyway.
  4. Log in when Krita opens.

If something does not work, message your experimenter — they can help you.
