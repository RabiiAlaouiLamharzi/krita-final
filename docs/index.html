Krita UI Learning Study

Install official Krita, then install our small study pack. Log in with the credentials your experimenter sent you. Works on macOS and Windows (use Krita 5.3.2).

Step 1 — Download Krita (official) Step 2 — Download study pack

Setup (macOS)

  1. Install Krita from krita.org/en/download. Choose the macOS build for version 5.3.2 if available (or the closest 5.3.x). Open Krita once so macOS trusts it (if asked “downloaded from the internet”, click Open).
  2. Download the study pack (button above) and unzip it.
  3. Start the study: Right‑click Launch Study.command → Open → Open (required the first time on Mac).
  4. The script installs the study plugin and opens Krita. Log in with your Participant ID, Condition, Session, and password.

Do not look for a custom “study Krita.app” in the zip. Use the official Krita you installed, plus Launch Study.command.

Setup (Windows)

  1. Install Krita from krita.org/en/download. Choose the Windows installer for version 5.3.2 (or closest 5.3.x). Open Krita once to confirm it runs.
  2. Download the study pack (same zip as Mac) and unzip it.
  3. Start the study: double‑click Launch Study.bat. If Windows SmartScreen appears: More info → Run anyway.
  4. The script installs the study plugin and opens Krita. Log in with your Participant ID, Condition, Session, and password.

What the study pack contains

  • Study plugin + install scripts (not a full copy of Krita)
  • Learning / recall UI with text and images on the right panel
  • No ffmpeg / no tutorial videos
