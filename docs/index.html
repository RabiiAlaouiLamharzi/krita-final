Krita UI Learning Study

Install Krita, download the study pack, then run Launch Study. Do this with the experimenter in Session 1.

Mac

  1. Install Krita from krita.org. Open it once, then quit.
  2. Download and unzip the study pack.
  3. Right-click Launch Study.command → Open With → Terminal.
  4. If macOS blocks it: System Settings → Privacy & Security → Open Anyway, then try again.
  5. Quit the Krita window that opened, then open Krita again and log in.

Windows

  1. Install Krita from krita.org (normal installer, not Microsoft Store). Open once, then quit.
  2. Download the study pack. Right-click the zip → Extract All… to the Desktop.
  3. Open the extracted folder.
  4. Double-click Launch Study.bat (More info → Run anyway if Windows warns you).
  5. When install finishes, open a new Krita and log in.
