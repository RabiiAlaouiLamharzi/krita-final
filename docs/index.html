Krita UI Learning Study

This is a short guide to install Krita. Do this with the experimenter in Session 1, before onboarding starts.

This study looks at how people learn tools and panels in a simplified version of Krita. You will complete short guided tasks and a few recall tests.

Mac

  1. Install Krita. Drag it into Applications, then open it once.
  2. Download and unzip the study pack.
  3. Right‑click Launch Study.command → Open With → Terminal.
  4. If macOS says it cannot verify the developer or identity of the program:
    • Open System Settings → Privacy & Security, scroll down to the Security section, then click Allow / Open Anyway for Launch Study.
    • Right‑click Launch Study.command → Open With → Terminal again.
  5. After Launch Study.command finishes installing, quit the Krita window that is currently open, then open a new instance of Krita.
  6. Log in when Krita opens.

Windows

  1. Install Krita, then open it once.
  2. Download and unzip the study pack.
  3. Double‑click Launch Study.bat. If Windows warns you, choose More info → Run anyway.
  4. Log in when Krita opens.
